# plc-learning-materials

## 理论材料内容

存储了武汉大学《程序语言理论与编译技术》课程的理论、Ocaml代码部分整理，方便有需求的同学学习和复习。

- **《程序语言理论与编译技术》课程实录笔记.md**：课堂理论知识笔记，是对PPT和讲解内容的系统性整理。
- **《程序语言理论与编译技术》课程实录笔记_带封面.pdf**：是上述整理的打印版。
- **《程序语言理论与编译技术》笔试备考册.pdf**：一些往年题目，在理论部分有相似之处，但不完全相同，可以参考。
- llvm-example：一些代码例子用来理解LLVM 的 IR逻辑。

**说明**：本项目不包含作业题、课件等涉及更新的内容。代码部分请切换到另外的分支。
