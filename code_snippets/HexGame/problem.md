**题目描述：**

编写一个程序，用于判断一局 Hex / Polygon 游戏的胜者（或无胜者）。

Hex（又名 Polygon 或 CON-TAC-TIX）是一种抽象棋类游戏，规则简单但策略性强。游戏在一个平行四边形的六边形格子棋盘上进行，由两名玩家轮流落子。每位玩家的目标是将自己的棋子从棋盘的一边连接到对边，最先完成连接的玩家获胜。

棋盘的四条边分配给两位玩家：每位玩家分别拥有两条相对的边。例如，一位玩家需完成从上到下的连接，另一位则需完成从左到右的连接。

你的任务是：**根据给定的棋盘表示，判断哪位玩家赢得了游戏，或是否无人获胜。**

注意：输入的棋局不一定是“公平”的（例如，一方可能比另一方多落了几子，或者棋盘不是正方形）。

---

### 输入格式：

棋盘由一个字符串数组表示，每一行是一个字符串，表示棋盘的一行，字符间可能有空格对齐。
棋盘中的字符包括：

* `.` 表示空格（未落子）
* `O` 表示玩家 O 的棋子（需要连接 **从上到下**）
* `X` 表示玩家 X 的棋子（需要连接 **从左到右**）

输入棋盘示例：

```
. O . X .
 . X X O .
  O O O X .
   . X O X O
    X O O O X
```

（每一行前导空格表示六边形的偏移，棋盘呈现为六边形排列）

---

### 胜利条件：

* 玩家 `O` 获胜：如果存在一条由 `O` 组成的路径，从最上方一行连通到最下方一行；
* 玩家 `X` 获胜：如果存在一条由 `X` 组成的路径，从最左列连通到最右列；
* 如果两者都未完成对应方向的连接，则没有胜者。

---

### 输出格式：

输出结果为：

* `"O"` 表示玩家 O 获胜
* `"X"` 表示玩家 X 获胜
* `"None"` 表示无人获胜

---

### 示例：

对于下列输入棋盘：

```
. O . X .
 . X X O .
  O O O X .
   . X O X O
    X O O O X
```

输出应为：

```
None
```

虽然玩家 O 有从左到右的连接，但其目标是从上到下，因此未获胜。玩家 X 同理。

---

### 附加说明：

* 棋盘可以是任意高度和宽度的平行四边形。
* 请考虑使用图搜索算法（如 DFS 或 BFS）寻找连接路径。
* 每个位置有 6 个可能方向（六边形邻接）。
* 函数应该满足 `connect (board: string list) : player option` 的原型，其中 `type player = X | O`
